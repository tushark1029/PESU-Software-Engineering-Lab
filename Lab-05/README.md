1. Install Python 3 and make sure the `py` launcher works in Command Prompt.
2. Double-click `run_lab5_analysis.bat`, or open Command Prompt in this folder and run:

   ```bat
   run_lab5_analysis.bat
   ```

3. Open the six report files under `reports/before/` and `reports/after/`.
4. Confirm that the final Pylint score is above 9.5, Bandit has no findings, and Flake8 has no output.
